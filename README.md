# Digital Signal Processing Analysis

A MATLAB-based project for studying basic Digital Signal Processing concepts.

## Topics Covered

- Discrete-time signal generation
- Sampling
- FFT-based frequency analysis
- Decimation
- Interpolation
- FIR filtering
- Time-domain and frequency-domain analysis

## Tools Used

- MATLAB

## Project Description

This project generates discrete-time signals and analyzes them in both time and frequency domains. FFT is used to identify frequency components, while decimation and interpolation are used to study sampling-rate changes. A moving-average FIR filter is also implemented to observe the effect of filtering on the signal.

## Output

The project generates plots showing:

1. Original time-domain signal
2. Frequency spectrum using FFT
3. Decimated signal
4. Interpolated signal
5. Original and filtered signals
6. Frequency spectrum after FIR filtering
